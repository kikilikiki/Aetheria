# Bio TikTok (≤ 80 caractères)

Bio pour le compte TikTok d'Aetheria. TikTok limite la bio à **80 caractères** (un emoji compte
en général pour 2). Le lien du jeu se met dans le champ « site web » séparé, pas dans la bio.

## Recommandée

```
Capture des créatures, explore des donjons, domine les royaumes 🐉 Jeu indé FR
```

*(78 caractères)*

## Alternatives

| Bio | Caractères |
|---|---|
| `Capture des créatures, explore des donjons, domine les royaumes 🐉 Jeu indé FR` | 78 |
| `Ton royaume. Tes créatures. Ta légende. Un MMO de capture 100% français.` | 72 |
| `🐉 Aetheria — capture, élève et combats des créatures dans un monde à conquérir` | 79 |
| `Capture. Combats. Conquiers. Le MMO de créatures made in France 🐉 Jouez gratuit` | 80 |
| `MMO de capture de créatures 100% FR • Donjons, royaumes en guerre, PvP • Gratuit` | 80 |

## Version multi-ligne (TikTok accepte les retours à la ligne)

```
🐉 MMO de capture de créatures
Donjons • Royaumes • PvP • Saisons
Jeu indé français — dispo maintenant
```

*(≈ 78 caractères sans compter les retours à la ligne)*

## Notes

- Emoji ≈ 2 caractères dans le compteur TikTok — les valeurs ci-dessus en tiennent compte.
- Pour recompter : `("<texte>").Length` en PowerShell (approx.), ou un compteur de caractères en
  ligne réglé sur « TikTok ».
