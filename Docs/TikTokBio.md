en général pour 2). Le lien du serveur Discord : `discord.gg/8NqXPsg7gE`.


## Notes

- Emoji ≈ 2 caractères dans le compteur TikTok — les valeurs ci-dessus en tiennent compte.
- La bio TikTok n'est pas cliquable : `discord.gg/8NqXPsg7gE` s'affiche en texte. Pour un lien
  cliquable, le mettre aussi dans le champ « site web » du profil.
- Pour recompter : `("<texte>").Length` en PowerShell (approx.), ou un compteur réglé sur « TikTok ».
